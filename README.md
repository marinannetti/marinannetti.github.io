** Incredibles 2 Sentiment Analysis**
NLP project analyzing the emotional arc of the Incredibles 2 script 
using a custom 13-category emotion lexicon built in Python. Includes 
stop word filtering, act-by-act breakdown, and a scene-level line graph 
tracking how key emotions shift across the narrative.
Tools: Python · NLTK · matplotlib
